## Primeiros passos

Boas-vindas ao ambiente de Java no editor de código. Abaixo vai um roteiro para começar a escrever código Java no editor.

## Estrutura de pastas

O espaço de trabalho traz duas pastas por padrão:

- `src`: onde ficam os fontes
- `lib`: onde ficam as dependências

Já os arquivos compilados vão para a pasta `bin`.

> Para mudar essa estrutura, ajuste as configurações no arquivo de preferências da pasta de configuração do editor.

## Gestão de dependências

A visão de projetos Java do editor permite administrar as dependências. A documentação da extensão explica como fazer isso em detalhe.
